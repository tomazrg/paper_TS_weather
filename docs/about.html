Data importation and pre organization

To ensure valid inference using a Distributed Lag Non‑Linear Model (DLNM), epidemiological observations and weather time series were first aligned in time and space and filtered to guarantee complete exposure histories. Disease severity was evaluated at a fixed assessment time (END_DAP), corresponding approximately to the R6 growth stage, and each epidemic was linked to its assumed assessment date. Daily weather data were then restricted to the period from planting (day 0) to the assessment day, ensuring that all lagged exposures used in the DLNM were fully observed. Only epidemics with complete daily weather records across the entire lag window were retained, as DLNM estimation requires a continuous exposure history for all lags considered. Vapor pressure deficit (VPD) was derived from mean temperature and relative humidity to represent atmospheric drying demand and leaf wetness persistence, which are epidemiologically more meaningful drivers of foliar disease development than relative humidity alone. A site–year identifier was constructed to capture unobserved spatial and temporal heterogeneity in subsequent mixed‑effects modeling. Finally, because disease severity was modeled using a beta regression, observations equal to 0 or 1 were slightly adjusted to satisfy the distributional assumptions of the beta likelihood. This preprocessing step establishes a consistent epidemiological time origin, guarantees complete lagged exposure information, and produces physically interpretable climatic covariates, thereby providing a sound foundation for constructing DLNM cross‑basis functions and estimating their effects within a generalized mixed modeling framework.

Templates to cross-basis (shared)

To model delayed and non-linear effects of climatic variables on disease severity, we adopted the Distributed Lag Non-Linear Model (DLNM) framework. Because disease severity is observed only once per epidemic—at a fixed assessment time—while climatic exposures are recorded daily, the DLNM requires a complete and consistently structured exposure history for each epidemic across the entire lag window.

For each climatic variable, daily exposure series were pooled across epidemics and concatenated with artificial separation gaps. These gaps prevent the propagation of lag effects from one epidemic into another, ensuring that temporal dependence is preserved within epidemics but not across them. This pooled representation allows the construction of a single shared cross-basis template per variable, guaranteeing that the same exposure–lag functional form is used for all epidemics.

Cross-basis templates were defined using natural cubic splines in both the exposure and lag dimensions. The degrees of freedom controlling exposure flexibility (DF_VAR) and lag flexibility (DF_LAG) determine the smoothness and complexity of the response surface but do not estimate any effects at this stage. Instead, these templates define the functional space within which the distributed lag effects are later estimated inside a generalized mixed modeling framework.

By constructing shared cross-basis templates prior to model fitting, this step ensures structural consistency, avoids repeated redefinition of spline geometries, and facilitates epidemiologically interpretable comparisons of climatic effects across lag periods and variables.

Let \(i = 1, \dots, N\) index epidemics, and let \(t_i\) denote the disease assessment time for epidemic \(i\). For a climatic variable \(v\) (e.g., rainfall, mean temperature, or vapor pressure deficit), let \(x_{iv}(t_i - l)\) represent the exposure at lag \(l\), where \(l = 0, 1, \dots, L\) and \(L\) is the maximum lag considered.

The DLNM assumes that the contribution of variable \(v\) to the linear predictor can be written as a smooth bivariate function of exposure and lag:

\[ f_v(x, l) = \sum_{k=1}^{K_v} \sum_{m=1}^{M_v} \beta^{(v)}_{km} \, B^{(v)}_k(x) \, C^{(v)}_m(l), \]

where:

  • \(B^{(v)}_k(x)\) are spline basis functions for the exposure dimension, with \(K_v = \text{DF\_VAR}\),
  • \(C^{(v)}_m(l)\) are spline basis functions for the lag dimension, with \(M_v = \text{DF\_LAG}\),
  • \(\beta^{(v)}_{km}\) are coefficients to be estimated in the inferential model.

The total contribution of variable \(v\) for epidemic \(i\) is obtained by summing across all lags:

\[ \eta_i^{(v)} = \sum_{l=0}^{L} f_v\!\left(x_{iv}(t_i - l),\, l\right). \]

These contributions enter the full model additively. For example, using a logit link for beta regression, the mean disease severity \(\mu_i\) is modeled as:

\[ \text{logit}(\mu_i) = \beta_0 + \sum_v \eta_i^{(v)} + u_{\text{siteyear}(i)}, \]

where \(u_{\text{siteyear}(i)} \sim \mathcal{N}(0, \sigma^2)\) represents a random intercept accounting for site–year–level heterogeneity.

Epidemic matrix (design)

Disease severity was observed once per epidemic at the assessment time, whereas climatic exposures were recorded daily over the entire growing period. To reconcile these different temporal resolutions within the DLNM framework, the lagged exposure histories of each epidemic were mapped onto epidemic-level covariates using pre-defined cross-basis templates.

For each climatic variable, the daily exposure series of an epidemic was transformed into a vector of basis coefficients corresponding to the last observed time point (the assessment day). This operation collapses the full distributed lag structure into a single row per epidemic while preserving the cumulative contribution of past exposures encoded by the DLNM. By applying the same cross-basis template to all epidemics, this step ensures that each epidemic is represented within a common functional space, allowing the resulting coefficients to be estimated consistently within a generalized mixed-effects model.

The resulting epidemic-level design matrix contains one row per epidemic and multiple columns per climatic variable, each column corresponding to a specific exposure–lag basis function. These columns serve as fixed-effect predictors in the inferential model, linking past climatic conditions to disease severity through the DLNM representation.

Let \(i = 1, \dots, N\) index epidemics, and let \(t_i\) denote the disease assessment time for epidemic \(i\). For a climatic variable \(v\), let \(x_{iv}(t_i - l)\) be the exposure at lag \(l\), with \(l = 0, 1, \dots, L\).

Using the previously defined cross-basis functions, the distributed lag contribution of variable \(v\) for epidemic \(i\) can be written as:

\[ \eta_i^{(v)} = \sum_{l=0}^{L} f_v\!\left(x_{iv}(t_i - l),\, l\right), \]

where the exposure–lag response surface is approximated by a tensor product of spline bases:

\[ f_v(x,l) = \sum_{k=1}^{K_v} \sum_{m=1}^{M_v} \beta^{(v)}_{km} \, B^{(v)}_k(x) \, C^{(v)}_m(l). \]

Here, \(B^{(v)}_k(x)\) are the spline basis functions for the exposure dimension and \(C^{(v)}_m(l)\) are the spline basis functions for the lag dimension. The coefficients \(\beta^{(v)}_{km}\) are estimated in the inferential model.

Evaluating the cross-basis at the final time point \(t_i\) yields a vector of basis values for each epidemic, denoted \(\mathbf{X}_i^{(v)}\). Stacking these vectors across all climatic variables produces the epidemic-level design matrix:

\[ \mathbf{X}_i = \left[ \mathbf{X}_i^{(\text{rain})}, \mathbf{X}_i^{(\text{tmax})}, \mathbf{X}_i^{(\text{vpd})} \right]. \]

This design matrix enters the generalized mixed-effects model as fixed effects:

\[ \text{logit}(\mu_i) = \beta_0 + \mathbf{X}_i \boldsymbol{\beta} + u_{\text{siteyear}(i)}, \]

where \(\mu_i\) is the mean disease severity for epidemic \(i\) and \(u_{\text{siteyear}(i)} \sim \mathcal{N}(0,\sigma^2)\) accounts for site–year–level heterogeneity.

extract_last_cb_row <- function(x, cb_template) {
  cb <- dlnm::crossbasis(
    x, lag = LAG_MAX,
    argvar = attr(cb_template, "argvar"),
    arglag = attr(cb_template, "arglag")
  )
  as.numeric(cb[length(x), ])

Framework modeling

Inferential framework and model fitting

After constructing epidemic-level DLNM design matrices, disease severity was modeled using a generalized mixed-effects framework. Because the response variable represents a proportion bounded between 0 and 1, a beta regression with a logit link was adopted. This formulation allows flexible modeling of the mean disease severity while respecting the bounded nature of the data.

The DLNM cross-basis coefficients derived for each climatic variable were included as fixed effects in the linear predictor, linking past climatic exposures to disease severity through their distributed and non-linear effects. To account for unobserved heterogeneity among epidemics conducted at different locations and years, a random intercept was specified at the site–year level. This hierarchical structure captures baseline differences in disease pressure that are not explained by the climatic covariates.

Importantly, the DLNM itself does not perform inference; rather, it defines the structure of the predictors. All statistical inference—including estimation of coefficients, uncertainty quantification, and hypothesis testing—is carried out within the mixed-effects beta regression model. Thus, this step represents the point at which the distributed lag non-linear effects are formally estimated and interpreted.

Let \(i = 1, \dots, N\) index epidemics, and let \(y_i \in (0,1)\) denote the observed disease severity at the assessment time. Disease severity is assumed to follow a beta distribution with mean \(\mu_i\) and precision parameter \(\phi\):

\[ y_i \sim \text{Beta}(\mu_i, \phi). \]

The mean \(\mu_i\) is linked to a linear predictor via a logit link function:

\[ \text{logit}(\mu_i) = \eta_i. \]

The linear predictor is specified as:

\[ \eta_i = \beta_0 + \sum_{v} \mathbf{X}_i^{(v)} \boldsymbol{\beta}^{(v)} + u_{\text{siteyear}(i)}, \]

where:

  • \(\beta_0\) is the global intercept,
  • \(\mathbf{X}_i^{(v)}\) is the epidemic-level DLNM design vector for climatic variable \(v\),
  • \(\boldsymbol{\beta}^{(v)}\) is the corresponding vector of fixed-effect coefficients,
  • \(u_{\text{siteyear}(i)} \sim \mathcal{N}(0, \sigma^2)\) is a random intercept capturing site–year–specific deviations.

Each design vector \(\mathbf{X}_i^{(v)}\) encodes the cumulative contribution of past exposures through the DLNM cross-basis evaluated at the assessment time:

\[ \mathbf{X}_i^{(v)} \boldsymbol{\beta}^{(v)} = \sum_{l=0}^{L} f_v\!\left(x_{iv}(t_i - l),\, l\right), \]

where \(f_v(\cdot,\cdot)\) denotes the exposure–lag response surface defined by the DLNM for variable \(v\).

This modeling step represents the inferential core of the analysis. The DLNM defines how climatic effects are structured across exposure levels and time lags, while the mixed-effects beta regression estimates the magnitude, direction, and uncertainty of these effects. The resulting model quantifies how past climatic conditions jointly shape disease severity at the assessment time, accounting for both delayed responses and unobserved heterogeneity among site–year combinations.

Model performance

After fitting the DLNM-based mixed-effects beta regression model, fitted values were obtained for each epidemic to quantify the model-implied mean disease severity at the assessment time. These fitted values represent the expected severity conditional on the estimated distributed lag non-linear effects of climatic variables and the random site–year effects.

Predictions were generated on the response scale, yielding values directly interpretable as mean disease severity proportions. By attaching these fitted values to the epidemic-level dataset, this step facilitates subsequent model evaluation, diagnostic checks, and graphical comparison between observed and model-implied disease severity. Importantly, these predictions are not used to refit the model; rather, they summarize how the inferred DLNM structure translates into expected epidemiological outcomes for the observed data.

Let \(y_i \in (0,1)\) denote the observed disease severity for epidemic \(i\), and let \(\mu_i\) be its model-implied mean. After fitting the mixed-effects beta regression model, predictions are obtained as:

\[ \hat{\mu}_i = \mathbb{E}(y_i \mid \mathbf{X}_i, u_{\text{siteyear}(i)}), \]

where \(\mathbf{X}_i\) is the epidemic-level DLNM design vector and \(u_{\text{siteyear}(i)}\) is the estimated random intercept for the corresponding site–year.

Using a logit link, the predicted mean is given by:

\[ \hat{\mu}_i = \text{logit}^{-1}(\hat{\eta}_i), \]

with linear predictor:

\[ \hat{\eta}_i = \hat{\beta}_0 + \sum_v \mathbf{X}_i^{(v)} \hat{\boldsymbol{\beta}}^{(v)} + \hat{u}_{\text{siteyear}(i)}. \]

Here, \(\hat{\beta}_0\) and \(\hat{\boldsymbol{\beta}}^{(v)}\) are the estimated fixed-effect coefficients, and \(\hat{u}_{\text{siteyear}(i)}\) denotes the best linear unbiased predictor (BLUP) of the random effect.

The resulting fitted values \(\hat{\mu}_i\) correspond to the expected disease severity at the assessment time, given the full distributed lag history of climatic exposures encoded by the DLNM.

Agreement between observed and model-implied severity (CCC decomposition)

To quantify how well the fitted model reproduces observed disease severity on the response scale, we evaluated agreement between observed severities (\(y_i\)) and fitted mean severities (\(\hat{\mu}_i\)) using Lin’s Concordance Correlation Coefficient (CCC). CCC measures both (i) precision (how tightly predictions follow the observed variability) and (ii) accuracy/bias (how close predictions are to the 1:1 line). This provides a single interpretable agreement metric that complements visual diagnostics.

We also report the two standard CCC components: the Pearson correlation (precision component) and the bias correction factor (accuracy component). Together, these summarize whether lack of agreement is driven primarily by random dispersion (low precision), systematic bias (low accuracy), or both.

Let \(y_i\) denote observed severity and \(\hat{\mu}_i\) denote the model-implied mean severity for epidemic \(i\). Define:

  • sample means: \(\bar{y}\) and \(\overline{\hat{\mu}}\)
  • sample variances: \(s_y^2\) and \(s_{\hat{\mu}}^2\)
  • sample covariance: \(s_{y,\hat{\mu}}\)

The Pearson correlation (precision component) is:

\[ \rho = \frac{s_{y,\hat{\mu}}}{s_y\, s_{\hat{\mu}}}. \]

Lin’s concordance correlation coefficient is:

\[ \rho_c = \frac{2 s_{y,\hat{\mu}}}{s_y^2 + s_{\hat{\mu}}^2 + (\bar{y}-\overline{\hat{\mu}})^2}. \]

It can be decomposed as:

\[ \rho_c = \rho \times C_b, \]

where \(C_b\) is the bias correction factor (accuracy component), with \(0 < C_b \le 1\), penalizing deviations from the 1:1 line due to differences in location and scale.

Graphical calibration and residual error distribution

To complement the CCC summary, we visualized model calibration by plotting observed severity (\(y_i\)) against fitted mean severity (\(\hat{\mu}_i\)) with a 1:1 reference line. Estimation of cumulative relative risks over epidemiologically defined lag windows

To summarize the distributed effects of climatic variables in an epidemiologically interpretable manner, relative risks were derived from the fitted DLNM by aggregating lag-specific contributions over predefined temporal windows. Rather than interpreting individual lag effects, which may be difficult to relate directly to biological processes, cumulative effects were computed for early and late lag periods corresponding to distinct phases of epidemic development.

For each climatic variable, the DLNM provides an estimated exposure–lag response surface describing how past exposures contribute to disease severity at the assessment time. By summing the lag-specific contributions across a given lag window and exponentiating the resulting linear predictor, a cumulative relative risk is obtained. This quantity represents the proportional change in expected disease severity associated with a given exposure level, relative to a reference value, accounting for the entire exposure history within the specified lag interval.

Lag windows were defined a priori to reflect biologically meaningful phases of the epidemic. The early window (0–40 days before assessment) captures processes related to infection establishment, latent development, and early lesion formation, whereas the late window (41–70 days) reflects symptom expansion and disease expression near the assessment stage. This aggregation facilitates direct comparison of climatic effects across variables and epidemic phases, while preserving the non-linear and delayed structure estimated by the DLNM.

Let \(i\) index epidemics and let \(t_i\) denote the disease assessment time. For a climatic variable \(v\), let \(x_{iv}(t_i - l)\) be the exposure at lag \(l\), with \(l = 0, 1, \dots, L\).

The DLNM defines an exposure–lag response surface \(f_v(x,l)\), such that the total contribution of variable \(v\) to the linear predictor is:

\[ \eta_i^{(v)} = \sum_{l=0}^{L} f_v\!\left(x_{iv}(t_i - l),\, l\right). \]

To obtain a cumulative effect over a specific lag window \(\mathcal{L} \subset \{0,\dots,L\}\), the contribution is restricted to that window:

\[ \eta_{i,\mathcal{L}}^{(v)} = \sum_{l \in \mathcal{L}} f_v\!\left(x_{iv}(t_i - l),\, l\right). \]

Relative risk is then defined with respect to a reference exposure value \(x_v^{\mathrm{ref}}\) (here chosen as the median of the observed exposure distribution):

\[ RR_v(x;\mathcal{L}) = \exp\!\left( \eta_{i,\mathcal{L}}^{(v)}(x) - \eta_{i,\mathcal{L}}^{(v)}(x_v^{\mathrm{ref}}) \right). \]

For ease of interpretation, relative risk is often expressed as a percentage change:

\[ \%\Delta_v(x;\mathcal{L}) = \left[ RR_v(x;\mathcal{L}) - 1 \right] \times 100. \]

build_pooled_series <- function(wx_long, var, sep_n = SEPARATOR) {
  ids <- unique(wx_long$epi_id)
  unlist(lapply(ids, function(id) {
    v <- wx_long |>
      filter(epi_id == id) |>
      arrange(dpp) |>
      pull(.data[[var]])
    c(v, rep(NA_real_, sep_n))
  }))
}

extract_last_cb_row <- function(x, cb_template) {
  cb <- crossbasis(
    x, lag = LAG_MAX,
    argvar = attr(cb_template, "argvar"),
    arglag = attr(cb_template, "arglag")
  )
  as.numeric(cb[length(x), ])
}

build_design_for_var <- function(wx_long, var, cb_template, prefix) {
  X <- wx_long |>
    group_by(epi_id) |>
    summarise(cb = list(extract_last_cb_row(.data[[var]], cb_template)),
              .groups = "drop")
  p  <- length(X$cb[[1]])
  nm <- paste0(prefix, seq_len(p))
  X |>
    mutate(cb = lapply(cb, setNames, nm)) |>
    unnest_wider(cb)
}

            wx_use,
            .x,
            cb_templates[[.x]],
            prefix = paste0("cb_", .x, "_")
          )
        )
        
        X <- reduce(X_list, left_join, by = "epi_id")
        
        dat <- epi_use |>
          select(epi_id, sev, siteyear) |>
          left_join(X, by = "epi_id") |>
          mutate(sev = sev / 100)
        
        cb_terms <- paste(names(dat)[grepl("^cb_", names(dat))], collapse = " + ")
        fml <- as.formula(paste0("sev ~ 1 + (1|siteyear) + ", cb_terms))
        
        # ---- ajuste do modelo ----
        fit <- try(
          glmmTMB(
            formula = fml,
            data = dat,
            family = beta_family(link = "logit")
          ),
          silent = TRUE
        )
        
        if (inherits(fit, "try-error")) next
        
        pred <- predict(fit, type = "response")
        ccc  <- epi.ccc(dat$sev, pred)
        
        results[[model_id]] <- tibble(
          model_id = model_id,
          DF_VAR   = DF_VAR,
          DF_LAG   = DF_LAG,
          vars     = paste(VARS, collapse = " + "),
          CCC      = ccc$rho.c[1],
          Cb       = ccc$C.b[1],
          rho      = ccc$rho[1]
        )
        
        model_id <- model_id + 1
      }
    }
  }
}
